Privacy Policy

Effective 25 November 2026. This policy covers the website storiesbyspiritai.github.io and the Spirit application.

Who we are

"Spirit" is an AI storyteller that publishes old folk tales, read slowly for sleep, on the YouTube channel @StoriesbySpiritAI and on Instagram and Facebook. The Spirit application is the private software that runs her channel. It is owned and operated by Gayantha Wijeyawardena, who is responsible for this policy.

This website

This website is a plain information page. It has no accounts, no forms, no cookies of its own, no advertising and no analytics. It loads its font from Google Fonts and is hosted on GitHub Pages, which may keep basic technical logs (such as IP addresses) for security, under GitHub's privacy statement.

What the Spirit application is

Spirit is not a public app. Nobody can sign up for it or sign in to it except the channel owner. It runs on the owner's own computer and connects only to the owner's own accounts: the Stories by Spirit AI YouTube channel, the Spirit AI Facebook Page and the @storiesbyspiritai Instagram account.

Google and YouTube data the application uses

Spirit uses YouTube API Services. With the owner's permission it uses the following Google access, only for the owner's own channel:

  • Manage the YouTube channel (youtube, youtube.force-ssl): upload videos and Shorts; set titles, descriptions, thumbnails, subtitles and playlists; read the public comments on Spirit's own videos and post replies to them.
  • View YouTube Analytics reports (yt-analytics.readonly): read the channel's own statistics, such as views, watch time, returning viewers and traffic sources, so Spirit can learn which tales people enjoy.

Viewer comments. When someone comments on one of Spirit's videos, the application reads the comment text and the commenter's public display name in order to write a reply. This is done on the owner's computer by a local AI model. Comments are not sold, not shared, not used for advertising and not used to build profiles of anyone. Only short-lived working copies are kept, so that the same comment is not answered twice.

Channel statistics are kept on the owner's computer and summarised in a private weekly email to the owner. They are aggregate numbers and do not identify individual viewers.

Instagram and Facebook data

Through the Meta Graph API, Spirit posts Reels and pictures to her own Instagram account and Facebook Page, and reads and replies to comments on her own posts, in the same way as on YouTube. The same limits apply: nothing is sold, shared or used for advertising.

Where data is stored and who sees it

Sign-in keys (access tokens) and all working data are stored only on the owner's own computer. The application does not send Google user data or comment data to any other company or AI service. The only people who can see it are the owner and, for public comments and replies, the public on the platform where they were posted.

Google API Services User Data Policy

Spirit's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Because Spirit uses YouTube API Services, the Google Privacy Policy also applies to data handled by YouTube and Google.

Removing access and deleting data

The channel owner can remove Spirit's access to the Google account at any time at myaccount.google.com/permissions, and to Meta accounts in Facebook's Business Integrations settings. When access is removed, Spirit stops using the account and the stored keys are deleted from the owner's computer. Anyone who would like a reply or other data about them removed can ask using the contact below, and it will be deleted within 30 days.

Children

Spirit's stories are for adults and older listeners winding down for sleep. The application does not knowingly collect information from children.

Changes

If this policy changes, the new version will be posted on this page with a new date.
